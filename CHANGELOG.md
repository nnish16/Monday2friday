### Added

- Dual-persona AI agents (F.R.I.D.A.Y. + M.O.N.D.A.Y.)
- AVCR framework bullet analysis and scoring
- Health score with red flag detection
- Multiple rewrite options per bullet with AI rationale
- PDF and DOCX upload support
- Skills categorization and gap detection
- Chat interface for follow-up questions
